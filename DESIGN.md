# Design System: 3D & App-First DevOps Engineer Profile

## Overview

A 3D-driven, application-icon-focused engineering identity system for Phan Trinh Tien Dat's GitHub profile (100% English). Prioritizes spatial 3D animations (`hero-3d.gif`), animated 3D isometric architecture diagrams (`architecture-3d.svg`), 3D-beveled telemetry widgets (`languages-breakdown.svg`, `github-activity.svg`), and recognizable rounded application icons (`skillicons.dev`) over dense walls of technical text.

## Layout & Information Architecture

1. **3D Hero & App Dock Banner (`assets/hero-3d.gif`):** Full-width 3D perspective cluster animation paired with a floating 3D App Icon dock (`K8S`, `DKR`, `AWS`, `TF`, `SPR`, `GHA`).
2. **Visual Overview:** 3-column bento summary highlighting Backend Services, Cloud & Containers, and GitOps & Telemetry with curated App Icon strips.
3. **App & Tool Ecosystem:** 2x2 visual App Icon dock (`skillicons.dev`, 4 icons per line) + Next-Gen Platform & Security app badges.
4. **3D Isometric Cloud Pipeline (`assets/architecture-3d.svg`):** Animated 3D isometric 5-stage delivery topology with floating slabs, glowing conduits, and moving telemetry packets.
5. **Featured Applications:** 2x2 project cards (`morph3d-ai`, `identity-service`, `java-core-mastery`, `devops-profile-engine`) powered by rounded App Icons.
6. **Certification Roadmap:** Transparent 3-column milestone showcase (`[GOAL]` / `[PLANNED]`) with official Kubernetes, AWS, and Terraform app icons.
7. **3D Telemetry & Activity:** 3D-beveled codebase volume cylinder (`assets/languages-breakdown.svg`) and live commit stream (`assets/github-activity.svg`) with collapsible raw links.
8. **Let's Connect:** Direct contact channels.
