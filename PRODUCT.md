## Users

Engineering recruiters, technical hiring managers, fellow backend and DevOps engineers, and open-source collaborators reviewing Phan Trinh Tien Dat's GitHub profile.

## Product Purpose

Establish a credible, compelling, and visually arresting engineering presence for Phan Trinh Tien Dat on GitHub. The profile showcases his actual backend engineering capabilities (Java/Spring microservices), containerization and cloud infrastructure practices (AWS, Kubernetes, Docker, Terraform), while maintaining complete transparency regarding future learning milestones and certification targets.

## Positioning

Unlike typical boilerplate GitHub profiles with generic static badge grids or unverified stats, this profile features a real 3D perspective animation of a Kubernetes container topology, verified live commit history across public repositories, accurate codebase byte metrics (forks strictly excluded), and transparently labeled certification goals.

## Operating Context

Displayed directly on `github.com/tiendat2712` across light and dark GitHub themes, mobile devices, and desktop viewports. Operates under GitHub Markdown constraints (no custom JS/CSS/canvas). Dynamic assets are automatically refreshed via scheduled GitHub Actions workflows.

## Capabilities and Constraints

- **Rendering:** Compatible with GitHub's image proxy (`camo.githubusercontent.com`), rendered as animated GIF and responsive SVG.
- **Data Integrity:** Strict avoidance of third-party fragile stats servers; data is synced directly from GitHub API with graceful offline cache fallback.
- **Transparency:** No fabricated claims, no mock data, certifications explicitly designated as `[GOAL]` / `[PLANNED]`.

## Product Principles

1. **Authenticity over Pretense:** Ground every metric, commit, and capability in verifiable public repository evidence.
2. **Dynamic Depth over Flat Templates:** Author an original 3D perspective kinetic experience instead of repeating static icon rows.
3. **Transparent Milestones:** Never blur the line between achieved competency and aspirational roadmap goals.
4. **Resilient Delivery:** Self-contained assets that never break or throw 502 bad gateway errors on the profile.
